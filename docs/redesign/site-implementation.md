## 1. 이번 요청과 변경 범위

사용자는 홈 시안의 가로 폭이 과하게 느껴진다고 지적하고, 그 방향을 실제 사이트로 확장하도록 요청했다. `/`는 이미 `ProductionHome`을 공유하고 있었으므로 홈을 다시 복제하지 않았다. 내부 페이지까지 같은 탐색과 폭으로 연결하고, 실제 회사 메뉴의 목적지를 구현했다.

이 문서가 [홈 구성 기록](home-composition.md) 8절 이후의 **현재 화면·경로 기준**이다. 과거의 내부 페이지 확장 보류는 이번 요청으로 해제됐다. 필름·브랜드·프로젝트 데이터·공개 정책·메일 API는 유지한다. 배포·외부 발송은 이번 작업에 포함하지 않는다.

## 2. 초기 적용값 — 전체 폭·높이 상한은 7절로 대체

| 항목 | 적용값 |
|---|---|
| 사이트 전체 최대 폭 | 1440px, 가운데 배치 |
| 1200px 이상 | 바깥 24px, 좌측 280px, 두 영역 간격 24px |
| 1024–1199px | 바깥 16px, 좌측 240px, 간격 20px |
| 1024px 미만 | 바깥 8px, 좌측 숨김, 기존 64px 모바일 헤더·목록 대화상자 |
| 1680×900 실제 측정 | 전체 x120·폭1440, 히어로 x424·y24·1136×852 |
| 1440×900 실제 측정 | 전체 x24·폭1392, 히어로 x328·y24·1088×852 |
| 홈 히어로 | 화면 높이−외곽 상하 여백, 최소560·최대1080; 모바일 최소580 유지 |
| 로고·색·사진·타이포 | 기존 퍼플 로고104px·#7500FF·브랜드 폰트·20초 필름 유지 |
| 내부 페이지 제목 | 중립 본문 서체, 최대44px, 모바일29px부터 |

외부 폭 제한과 좌측 320→280px 조정을 함께 적용했다. 1440px 화면의 히어로 폭은 직전 1084px에서 1088px로 거의 같다. 더 넓은 화면에서 계속 늘어나는 것을 제한하는 목적이며, 모든 화면을 일괄적으로 축소하는 규칙은 아니다. 내부 텍스트는 추가 본문 여백과 문단 최대 폭으로 읽기 길이를 관리한다.

낮은 화면에서 히어로 최소 높이를 유지하며 자연스러운 세로 스크롤을 허용한다. 목록만 필요한 만큼 스크롤되고 하단 문의 경로는 남는다. 높이400px 미만 데스크톱은 좌측 고정을 해제하는 기존 원칙을 유지한다.

## 3. 실제 사이트의 탐색과 페이지

| 주소 | 구현 |
|---|---|
| `/` | 기존 홈·필름, 공통 폭과 왼쪽 메뉴 적용. 각 요약에서 독립 페이지로 연결 |
| `/portfolio` | 기존 검색·분류·프로젝트 이력, 공통 좌측 색인 |
| `/portfolio/[slug]` | 기존 상세 주소·본문·사진·역할·제외 범위 유지, 같은 탐색 틀 |
| `/capabilities` | 기획·연출 / 프로덕션·현장 운영 / 디지털 경험, 실제 수행 예시·문의 |
| `/about` | 기존 승인 문구 기반 회사 소개·일하는 방식·실적·제품 경로 |
| `/products` | 포도나무·LIVE TEXT·두줄자막. 기존 공식 주소·보유 UI 사용 |
| `/inquiry` | 밝은 폼·명시적 필드 레이블·문의 안내. 기존 API와 메일 처리 유지 |
| `/services` | `/products`로 308 영구 이동. 기존 설계 경로 매핑 적용 |
| `/privacy`, `/terms` | 기존 본문 유지, 공통 탐색·폭 적용 |
| `/design-system` | 디자인 시스템 보드 보존 |
| `/design-system?view=home` | 홈 시안 검토용. 같은 `ProductionHome`·`SiteFrame`, 회사 메뉴는 기존 구간 앵커 |

실제 사이트에서는 회사 메뉴가 `/capabilities`, `/about`, `/products`로 이동한다. 검토 화면의 회사 구간 앵커와 구분했다. 현재 페이지는 `aria-current=page`, 검토 화면의 현재 구간은 `aria-current=location`으로 표시한다.

홈은 대표 여섯 작업과 원래 순서를 유지한다. 내부 페이지는 공통 모델에서 읽은 연도별 전체 이력으로 전환한다. 개발 환경의 35건과 운영 공개 필터를 통과한 3건을 구분하며, 빈 항목을 임의로 채우지 않는다. 모바일은 같은 데이터와 제목 연도 정리 함수를 사용한다. 내부 페이지의 이전 공통 하단 이미지 프리뷰는 새 색인에서 사용하지 않는다.

본문 건너뛰기 링크는 오른쪽 콘텐츠로 이동하고 키보드 포커스도 전달한다. Next Link를 유지하여 URL과 라우터 이력이 갈라지지 않게 한다. 홈에서 실제 상세로 이동했다가 뒤로 가는 경우 본문·색인 위치를 복원하는 기존 기능을 유지한다.

회사 소개의 SOS 제작석 사진과 제품 UI는 기존 개발 검토 파생본을 사용한다. 운영 빌드에는 넣지 않는다. 이미지가 없을 때도 제목·내용·링크가 남으며, 빈 이미지 링크나 고정 너비의 공백 열을 만들지 않는다.

원본 콘텐츠, 브랜드 파일, 필름 출력, 필름·타이포 컴포넌트, 공통 프로젝트 표시 모델, 분석 및 API 등 **78개 보호 파일의 SHA-256이 작업 전후 동일**하다. 입력 원본을 수정하거나 공개 폴더로 옮기지 않았다. 새 회사 정보·실적 수치·역할을 임의로 추가하지 않았다.

## 6. 남은 확인과 운영 범위

- 사용자의 페이지별 시각 검토·문구 최종 승인.
- 프로젝트 사진·필름·제품 UI의 공개 승인. 로컬35건을 그대로 운영 공개한 상태가 아니다.
- 실제 수신함까지의 메일 전달, 운영 서버 설정·실사용 성능·배포 이미지 검증.
- OS 모션 감소, JS 비활성, 200% 확대, 실기기 브라우저 UI, 새로고침을 포함한 장기 이력 복원은 이번에 실제 검수하지 않았다.
- 필름20초 전체와 반복 경계는 이번 변경으로 재편집하거나 전수 재검수하지 않았다. 기존 필름 검수는 [당시 기록](home-composition.md)에 보존하며, 이번에는 해시 동일성과 현재 화면 재생/정지 상태를 확인했다.

실제 사이트의 로컬 주소는 `http://127.0.0.1:3017/`이다. 검수용 운영 빌드는 별도 로컬3019에서 확인했으며 외부 서버에 배포하지 않았다.
