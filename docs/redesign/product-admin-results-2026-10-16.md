## 사용 방법

관리자 → 제품 관리(`/admin/products`)에서 포도나무, LIVE TEXT, 두줄자막을 선택한다. 한 줄 소개·상세 설명·화면 이미지·대체 텍스트·캡션을 편집하고 저장한다. JPG·PNG·WebP 최대 8MB를 받으며 화면 숨김과 새 이미지 재등록도 가능하다.

포도나무와 LIVE TEXT는 홈과 제품 페이지가 같은 데이터를 읽는다. 두줄자막은 제품 페이지에 반영된다. 이미지가 없으면 화면 영역을 생략하고 남은 콘텐츠로 배치한다. 제품 신규 생성이나 현장 사진·적용 사례 편집은 이번 범위가 아니다.

## 저장과 운영 반영

`content/products/*.json`과 새 이미지 파일을 기존 관리자 저장소로 함께 저장한다. 로컬은 파일 저장, GitHub가 설정된 운영 관리자는 저장소 커밋 방식이다. 새 파일명으로 저장해 이전 배포의 이미지와 복구 경로를 유지한다. 운영 화면은 빌드·배포 후 반영되며 저장 성공과 운영 반영을 구별해 안내한다.

기존 세션 인증·동일 출처 검사·요청 크기 제한·이미지 실체 검증을 재사용한다. 편집 시작 시점과 저장 직전의 파일 버전을 비교해 다른 편집자의 변경을 덮어쓰지 않는다. 실패 시 입력을 유지한다. standalone 빌드에 제품 JSON을 포함한다.
