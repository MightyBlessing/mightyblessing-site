2026-10-17 · 로컬 수정·검수 완료 · 커밋·푸시·운영 배포 없음

## 수정

1. 수행 범위는 업무 태그 또는 수행 설명이 있으면 표시한다. 태그가 없는 설명도 보이고, 둘 다 비어 있으면 영역을 생략한다.
2. 제품 화면 숨김은 `screenHidden`으로 관리한다. 이미지 경로·크기·대체 텍스트·캡션을 유지하고, 공개 로더에서만 숨긴다. 재접속 후 체크 해제와 저장만으로 원래 화면을 복원한다. 이전 데이터에 플래그가 없으면 기존처럼 표시한다.
3. 관리자 미리보기는 인증된 `/api/admin/products/[id]/screen` 경로에서 저장소의 최신 이미지를 읽는다. 배포된 정적 파일에 의존하지 않는다. 비로그인 조회와 허용 범위 밖 경로를 거부하며 `private, no-store`로 응답한다. GitHub Contents의 1MB 초과 파일은 blob 읽기로 처리한다.
4. 제품 편집 중 저장하지 않은 변경이 있으면 공통 메뉴를 포함한 링크 이동을 캡처해 확인한다. 취소하면 입력과 파일 선택을 유지한다. 새 탭·다운로드·같은 화면 내 앵커는 편집기를 떠나지 않으므로 경고하지 않는다. 페이지 새로고침·닫기의 기존 경고도 유지한다.
