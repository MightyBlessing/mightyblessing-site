## 담당자 배포 후 확인

홈 영상·일시정지, 프로젝트 목록 30건, CAMPUS 상세 사진, 제품 적용 사례, 블로그 이동을 확인한다. `/services`의 `/products` 이동과 기존 상세 URL도 유지되어야 한다. 보류 사례(`/portfolio/fia-welove-2026` 등)는 404여야 한다.

`/sitemap.xml`에 새 공개 사례가 포함되고 이미지·영상 요청이 200/206인지 확인한다. 문의 실제 수신은 운영 환경에서 별도로 확인한다. GitHub 이미지 빌드 성공은 운영 서버 적용 완료를 뜻하지 않는다.
